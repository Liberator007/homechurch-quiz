## Устройство сайта

- Статический сайт без сборки: `index.html`, `css/style.css`, `js/data.js` (содержимое), `js/app.js` (движок), `js/sound.js`.
- Каждый раунд: «Суть» из Notion (поле `about`, без правил и очков) → вопросы (номер → вопрос + таймер сбоку) → список ответов, открываются по одному.
- Команд и подсчёта очков на сайте нет — только вопросы, время и ответы.
- Звуки: `assets/sounds/NN_имя.mp3`, громкость выровнена (`loudnorm I=-16`), тишина в начале обрезана.
- Картинки «Крупного плана»: `assets/closeup/<prefix>_1.jpg` (крупный план) и `_2.jpg` (целиком).
  Вопрос: номер → клик → только крупный план + таймер → клик → следующий предмет.
  Ответы (`closeupAnswers`): для каждого предмета по кликам крупный план → целиком → слово-ответ.
- Раунды: 1 «Нарисуй ответ» (`draw`), 2 «Звуки детства» (`sounds`), 3 «Угадай по эмодзи» (`qa`, style emoji),
  4 «Крупный план» (`closeup`), 5 «Угадай предмет на ощупь» (`touch` — только слайд с названием, без ответов),
  6 «Угадай по кадру» (`frames`, картинки `assets/frames/`, ответы — сетка `framesAnswers`),
  7 «Всё обо всём» (`qa`, варианты в `options`), 8 «Блиц» (`qa`, картинка `assets/blitz/`).
- Время раундов меняем только по прямой просьбе пользователя.
- Проверка: скриншоты через Playwright из scratchpad, Chromium в `/opt/pw-browsers/chromium-*/chrome-linux*/chrome`.

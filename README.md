# Викторина · Домашка 04.10.2026

Сайт-презентация для проектора: показывает вопросы, время на ответ и ответы. 6 раундов.
Работает **без интернета** и без установки — это обычные HTML-файлы.

## Как запустить

1. Скачать репозиторий: на GitHub **Code → Download ZIP** (или `git clone`), распаковать.
2. Открыть `index.html` в **Google Chrome** (двойной клик).
3. Перетащить окно на проектор и нажать **F** — полный экран.

Если что-то не грузится из файла (бывает в некоторых браузерах), запустите маленький сервер
в папке проекта и откройте http://localhost:8000:

```
python3 -m http.server 8000
```

## Как устроен показ

Каждый раунд: **суть раунда → вопросы → ответы**.

- Вопрос: сначала на экране только его номер, по клику открывается сам вопрос и запускается время
  (оно показано справа). Следующий клик — следующий вопрос.
- После последнего вопроса раунда — список всех вопросов. Ответы открываются по одному, по клику.
  Пояснение видно у последнего открытого ответа.
- Если номер перед вопросом не нужен, поставьте `numberFirst: false` в начале `js/data.js`.

## Управление

| Клавиша | Что делает |
|---|---|
| **Клик мышью**, **→**, **Пробел**, **PgDn** | Дальше: открыть вопрос и запустить время → следующий вопрос → открыть следующий ответ |
| **Правый клик**, **←**, **PgUp** | Назад (в списке ответов — скрыть последний открытый) |
| **P** | Пауза / продолжить время |
| **R** | Запустить время заново |
| **O** | Список всех слайдов, переход в любое место, **запасные вопросы** раунда 1 |
| **F** | Полный экран |
| **T** | Светлая / тёмная тема (светлая — для светлого зала) |
| **B** | Чёрный экран |
| **M** | Выключить / включить сигналы таймера |
| **H** | Подсказка по клавишам |

Пульт-презентер работает (он нажимает PgUp / PgDn). Клавиши работают и в русской раскладке.
При движении мышью в правом нижнем углу появляются кнопки ведущего.
Сайт запоминает, на каком слайде вы остановились.

## Особенности раундов

1. **Слепи ответ.** Время: 1 минута на обсуждение и лепку. Запасной вопрос открывается через **O**;
   если запасной вопрос показывали, его ответ появится в списке ответов раунда.
2. **Звуки детства.** Клик — звук играет два раза с паузой, затем 15 сек на запись.
   В списке ответов при открытии каждого ответа звук играет ещё раз.
3. **Чего нет в Библии?** Утверждение и 15 сек. В ответах: ЕСТЬ / НЕТ, пояснение и ссылка.
4. **Крупный план.** Клик — крупный план предмета и 15 сек, следующий клик — следующий предмет.
   В ответах по кликам для каждого предмета: крупный план → предмет целиком → слово-ответ.
5. **Перевёртыши.** Загадка и 30 сек. В ответах — оригинал.
6. **Собери порядок.** Пять волн по 6 карточек, на каждую 1 минута. В конце раунда — ответы
   по каждой волне отдельно: правильный порядок с годами или ссылками на Библию.

## Как поменять тексты

Все вопросы, ответы и правила — в файле `js/data.js`. Его можно редактировать прямо на GitHub.

## Устройство

- `index.html` — страница
- `css/style.css` — дизайн (цвета раундов — в начале файла)
- `js/data.js` — содержимое викторины
- `js/app.js` — слайды, навигация, таймеры
- `js/sound.js` — звуки и сигналы
- `assets/fonts/` — шрифт Onest (лицензия SIL OFL)
